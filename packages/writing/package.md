# Package: Writing

Use this package for writing, editing, manuscript development, argument improvement, essays, articles, sermons, proposals, and reader-facing communication.

## Components

- Council: `councils/writing.md`
- Chair: `chairs/editor-in-chief.md`
- Executor: `executors/writing-executor.md`
- Reviewer: `reviewers/copy-editor.md`

## Default workflow

1. Run Writing Council.
2. Run Editor-in-Chief Chair.
3. If user wants revisions, run Writing Executor.
4. If revisions are produced, run Copy Editor Reviewer.
5. Produce final report with advisor appendix.

## Package-specific guidance

- The primary user-facing output should be the Controlled Convergence Report, not raw advisor output.
- The Writing Executor should produce drafts only for the changes the Chair identifies as worth making.
- Preserve author voice.
- Avoid turning every critique into a revision.
