# Package Selection

Choose the most specific package that fits the request.

## Writing package

Use `packages/writing/package.md` for:

- essays
- book chapters
- blog posts
- sermons
- arguments
- newsletters
- proposals
- manuscript development
- audience clarity
- revision planning

## Engineering package

Use `packages/engineering/package.md` for:

- software architecture
- infrastructure
- API design
- refactors
- migrations
- scaling choices
- reliability/security/performance tradeoffs
- implementation planning
- PR or patch preparation

## Custom package

If no public package fits, build a temporary package with:

- 4–6 Council advisors representing competing concerns
- one Chair persona that embodies the user's priorities
- one Executor suited to the deliverable
- one Reviewer suited to validation

Keep the core workflow unchanged.
