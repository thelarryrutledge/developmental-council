# Context Isolation Matrix

| Component | Bare artifact | Enriched context | Audience/scope | Advisor outputs | Chair report | Executor output |
|---|---:|---:|---:|---:|---:|---:|
| Council advisors | yes | role-dependent | usually no | no | no | no |
| Outsider-style advisor | yes | no | no | no | no | no |
| Chair | yes | yes | yes | yes | no | no |
| Executor | yes | yes | yes | optional | yes | no |
| Reviewer | yes | yes | yes | optional | yes | yes |

## Key rule

Independence matters only during the Council phase.

After the Council phase, later stages are allowed to see earlier outputs because their job is synthesis, artifact creation, and verification.
